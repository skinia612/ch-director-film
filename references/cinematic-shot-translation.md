# 镜头视觉转译门

本文件用于 B 精确导演分镜。它解决“字段齐全、焦段运镜都有，但成片仍像廉价短剧”的问题。镜头语言不是给事件配一个中景和横移，而是选择观看位置，让动作改变画面结构与观众获得信息的方式；最终镜头必须不能被普通中景覆盖替代。

## 一、覆盖镜头判定

出现任意两项，先判为覆盖式镜头并重写：

- 机位是岸边、走廊、桌旁或房间正面的中性平视，摄影机只负责看清事件；
- 人物与摄影机同方向、近似同速移动，主体大小和前后景关系几乎不变；
- 起始是人物准备动作，结束只是人物完成动作并站稳、坐下或看向对方；
- 横移一米、短推几十厘米或稳定跟随没有显露新空间、改变权力位置或转移注意力；
- “自然眼神确认、轻微呼吸、道具露出”被附加在结尾，却不是动作和构图变化的物理结果；
- 删除摄影机运动后，观众得到的信息、情绪和结束图像完全不变；
- 可以用一句“中景拍人物完成动作”无损替代整段描述。

覆盖镜头不等于固定镜头。固定镜头可以有电影性；无功能的移动镜头同样可能只是短剧覆盖。

## 二、逐镜内部转译句

写硬合同前，内部先完成一句：

```text
起始视觉命题 → 动作触发 → 观看关系变化 → 结束图像
```

- **起始视觉命题**：第一帧已经存在明确的空间方向、遮挡、失衡、距离、光区、视线阻力或前后景层级；不是“人物准备做事”。
- **动作触发**：人物、道具、环境或声音启动变化；摄影机不能抢在动作前炫技。
- **观看关系变化**：只选择一个主变化——景别、纵深、遮挡、轴线、焦点、光区或画面重心。
- **结束图像**：最后一帧形成新的空间或关系状态，并提供动作切、遮挡切、声音桥或几何停点；不是补拍首饰和表情。

这句话只用于内部规划，最终仍输出原有逐镜字段，不新增“视觉命题”解释栏。

## 三、可选的单镜转译机制

每镜只选一个主机制，必要时增加一个次级结果：

1. **平面穿越**：人物穿过门槛、窗影、船岸、帘幕或人群边界，前后空间关系发生变化；
2. **遮挡显露**：有场景意义的画布、门、人物肩背、车辆或绳索随动作移开，显露新人物、出口或关系位置；
3. **纵深交换**：前景人物退入中景、中景人物进入前景，或两人交换焦平面与画面主次；
4. **反向矢量**：人物与摄影机不同向或不同速运动，背景视差、空间阻力或距离因此可读；
5. **光区跨越**：人物因真实路线进入或离开光池，面部、服装和环境同时改变；
6. **重心传递**：重量、碰撞、牵引、船体起伏或道具交接改变人物重心，并重新组织双人站位；
7. **焦点接管**：动作结束后注意力从真人转移到空位、道具、倒影或另一人物；全片少量使用，不连续拉焦。
8. **时间与注意力积累**：摄影机可以固定、构图可以克制；由画外声音、沉默长度、不同步表演或负空间让观众的注意力重新分配。必须产生清楚的关系变化，不能只剩呼吸和凝视。

不要把这些机制当运镜菜单平均分配。所选导演语法决定哪些机制成立，故事动作决定何时触发。

## 四、摄影机运动成立条件

- 横移必须跨过一个有意义的前后景关系，或让原本重叠的人物、出口、道具分开；不能只跟着人物走。
- 推近必须在人物认知、关系距离或信息可见度发生变化时停止；不用推近代替表演。
- 跟随必须选择明确观察位置，如船内、门口、队伍内部或人物身后，并让这个位置影响画面受力；不做无立场稳定器漫游。
- 短弧移必须使双人关系、门口压力或第三者位置发生变化；不以角度变化本身制造“高级感”。
- 固定镜头必须有内部视觉或注意力变化：人物跨层、遮挡移动、焦点接管、光区改变、背景行动，或由声音、沉默和不同步表演改变注意方向与负空间含义，至少一项。

## 五、结束画面与裁决顺序

结束画面至少满足一项：

- 人物与空间的距离、方向或主次已经改变；
- 原本被遮挡的信息完成显露，或重要信息重新被遮住；
- 画面重心转交给另一人物、空位、出口、道具或环境后果；
- 动作产生真实余波，如船岸分离、绳索松紧改变、门扇回弹、焦点留在原处；
- 光区或几何关系形成清楚的剪辑停点。

“双脚站稳、自然对视、轻微呼吸、衣摆停下、饰品或手记露出”单独出现均不算电影性结束。

裁决顺序：

1. 先检查覆盖项；命中两项以上直接重写，不能用船体回弹、光影漂亮或结尾道具露出抵消；
2. 命中零至一项时，再检查内部转译句与结束画面；
3. 最后执行输出前五问，任意两问答不清仍需重写；
4. 一个局部余波只算次级结果，不能单独证明整镜成立。

## 六、反馈反例：码头登船

覆盖式写法：

```text
35mm 岸边平视中景；女旅人踏上船，船工拉绳；摄影机沿岸平行横移一米，终点落在她站稳，二人短暂对视，朱红手记露出。
```

问题：摄影机与动作平行，首尾仍是岸边中景；登船结果从开始就已知，对视和手记只是尾部附加信息，横移没有改变观看关系。

最小转译示例，只使用“重心传递”作为主机制：

```text
40mm 胸口高度，摄影机固定在船体内部，第一帧让女旅人一脚在岸、一脚在船，身体横跨船岸边界。她把重量完全转移到船上时，船体下沉并向外荡开，摄影机只随船产生一次真实起伏；岸线因此在背景向外滑动。她抓住舷边站稳，外套被动作带开，朱红手记自然显露。结束时她与摄影机都已属于船上空间，身体和岸之间出现清楚水面间隔。
```

这里的电影性来自观察位置、船体受力和船岸距离共同改变，不依赖前景绳索、低机位、更多参数或额外慢动作。

同一内容还可以选择不同主机制，不能机械复制上例：

- **岸边固定版**：摄影机保持岸边眼平固定中景，人物登船后不跟随；船体回弹并逐渐离岸，使原本重叠的女旅人与船工分到不同纵深，结束画面把两人隔在船岸两侧。
- **遮挡显露版**：只有当真实船篷或舱门随登船动作移动并显露目的地、同行者或出口时才使用；没有新信息就不加遮挡。

## 七、稳定中景正例

稳定观察不需要强行添加低机位、前景或运镜：

```text
50mm 眼平固定双人中景，两人坐在餐桌两侧，中央空椅形成明确负空间。画外门响后，右侧人物停止斟茶但仍低头，左侧人物的视线转向空椅；摄影机不动，也不拉焦。沉默持续到茶水从壶嘴停止，结束时两人的注意方向共同压向中央空位，原本中性的空椅成为关系压力。
```

这类镜头以“时间与注意力积累”为主机制。首尾几何可以接近，但观众的注意地图、人物同步关系和负空间含义必须发生变化；只有呼吸、眨眼或长时间凝视仍不成立。

## 八、泛化检查与输出前五问

不要只用已知码头反例检查。生成后从当前草稿中选择一个未在本文件示范过的镜头，确认同一规则仍成立：

- 走廊跟拍不能只保持人物居中，应由门口、人流、转角或不同速度改变空间关系；
- 车站或车厢不能只让背景移动，应让到站、车门、乘客流向或窗光改变人物位置与注意力；
- 餐桌和室内文戏不强求运镜，以负空间、不同步动作、声音进入和时间积累完成关系变化。

1. 第一帧是否已经有可辨识的空间命题，或稳定镜头所需的注意力、时间与负空间命题，而不是演员等着动作？
2. 摄影机为什么在这里；换成正面中景会损失什么？
3. 动作或声音具体改变了景别、纵深、遮挡、轴线、焦点、光区、重心、注意方向或时间关系中的哪一项？
4. 首尾画面并排时，能否看出新的空间、关系或注意力状态；若几何接近，持续时间和不同步表演是否足以改变含义？
5. 删除焦段、轨道距离和“电影感”形容词后，这仍是一种不可被普通覆盖镜头替代的观看方式吗？

任意两问答不清，重写镜头。不要靠增加前景、晃动、低机位或快速剪辑掩盖问题。

## 九、固定回归样本

更新本 Skill 时至少用下列三种不同场景回归，不能只复测码头：

- **应拒绝｜走廊**：35mm 眼平中景平行跟随人物走到办公室门口，人物停下回头，摄影机停止；没有新空间、关系或注意力变化。
- **应通过｜餐桌**：50mm 眼平固定双人中景，画外门响造成两人不同步停顿，注意力共同压向中央空椅；摄影机不动，几何接近但负空间含义改变。
- **应拒绝｜车站**：人物站在月台中景，列车在背景驶过，摄影机轻推，人物继续凝视前方；背景运动没有改变人物路线、遮挡、关系或注意方向。

回归目标是区分“移动摄影机不一定有镜头语言”和“固定摄影机不一定廉价”，不是要求所有场景复制同一种视觉装置。
