# 输出前目标—观感审稿闭环

本文件用于所有 A/B 提示词的最终审稿。目标不是增加解释，而是在输出前判断“模型按字面执行后，观众实际会看到什么”，并用独立审稿纠正乐观想象与提示词之间的偏差。

## 一、先反推预期观感

只根据已写入提示词的可见控制，内部生成 2–4 句预期观感，依次回答：

1. 观众首先看到的主体、时代空间和主要动作是什么；
2. 景别、运动与剪辑形成怎样的节奏，快剪是否真的快，稳定观察是否仍有内部变化；
3. 人物关系或情绪通过哪些表情、身体、距离、道具或光区变化成立；
4. 光源、肤质和材质最终更接近电影、电视剧、写真、广告还是 AI 短剧。

- 每个观感判断必须能回指至少一项画面指令；“史诗、宿命、灵动、高级、逐渐掌握命运”等抽象结论若缺少两项可见支持，删除或降级。
- 观感描述不能替提示词补剧情。提示词只写人物离开，不能把观感夸大成“她完成自我救赎”。
- 同时预测一个最可能的生成风险，例如镜头过载、动作过细、表情僵硬、冷暖模板化或快剪不足。

## 二、目标一致性对照

内部建立三列对照，不默认输出：

```text
用户锁定目标｜提示词中的可见证据｜反推的预期观感
```

至少检查：

- 题材、时代、人物身份和参考图约束；
- 所选导演主机制是否改变构图、运动、光影或表演至少两项；
- 人物关系、情绪和表演是否由触发—反应—物理承接成立；
- 镜头数量、单镜时长与“快剪/舒缓/压迫/宏大”等节奏目标是否相符；
- B 模式逐镜是否通过 `cinematic-shot-translation.md`，摄影机是否改变观看关系而非平行记录动作；
- 环境、配角、光源、皮肤和材质是否共同支持目标质感；
- 负面约束是否与正向正文矛盾。

用户明确要求电影预告片时，额外检查：

- 是否能用一句话说清观感契约：题材气质、主导演可见机制、人物银幕气质、能量曲线与余韵；不要求剧情命题或未解问题。
- 逐镜检查主要画面价值、导演机制、人物表现和景别差异；镜头无需增加剧情信息，但不能只靠导演姓名、服装展示、景区显露或音乐重音成立。
- 全片是否同时具有人物表现、导演签名构图或光影、独立题材事件、环境参与和至少一次制作峰值；不强制引入对手、异常规则或中心悬念。
- 相邻镜头能否被理解为同一事件的连续过程；若整段可按时间顺序无障碍复述，判为“压缩叙事”，需重组。
- 将加速段连续三至五个闪切单独连读；若动作、道具或视线能组成发现—接近—行动—完成的局部因果链，判为需修改。每组通常是独立事件，全片最多一组两个镜头具有清楚关联。
- 全片是否至少出现三次跨时间、空间、尺度、人物状态或光影状态的跳变，且最多只有一组局部动作—反应连接。
- 镜长是否有明显长短差，是否存在短促呼吸与最终按钮，而不是十镜等长或五镜平铺。
- 是否只有 2–4 个主要音乐同步点；若每次鼓点都切画面，判为机械 MV。
- 是否至少有一个生产声音桥或 J/L cut，把非连续画面组织为同一作品世界。
- 结尾是否留下人物余韵、动作峰值、环境回声或标志性构图，而非解释结果或长时间凝视；地标镜头是否通过导演式造型、人物尺度、群像或环境变化区别于旅游宣传片。
- B 模式是否把每个实景锚点绑定到确定参考图并消除“或/任选”式备选；反复出现的道具是否已锁定有无、位置和持有者。
- 逐个抽查闪切镜头：能否画出摄影机位置、拍摄方向、左右边界、纵深终点、前中后景元素和主体画面区域；任一项只能靠模型猜测时，判为轻量合同不完整。
- 使用场景参考图时，检查镜头空间是否能从原图直接读出；若出现原图未显示的廊道延伸、建筑拼接、采光开口或可通行路线，判为参考图空间幻觉并重写。

视频类型为 MTV / 音乐影像时，额外检查：

- 是否锁定歌曲来源、片段位置、节奏变化、人声状态、表演身份和视觉副歌；缺少歌曲时是否明确使用原创无歌词结构，而非伪造口型。
- 镜头是否真正响应主歌、副歌、停顿、旋律、人声换气、歌词意象或音色变化，而不是只在所有鼓点机械切镜。
- 是否至少有一个较完整的艺人/主角表演锚点；舞者、造型、环境、特效和产品是否压过主体身份。
- 视觉副歌是否在重复时改变规模、动作、构图、光区或群体，而非原样重放；表演、概念和叙事是否最多保留一个主形态与一个辅助形态。
- 可见演唱、演奏和舞蹈是否具备正确歌词段落、口型、手位、身体重心和落脚；未要求演唱时人物是否避免无意义张嘴。

视频类型为高端文旅宣传片时，额外检查：

- 是否能明确说出目的地身份、品牌气质、核心体验、在地人物、地域声音和记忆母题；替换地名后仍成立时必须重写。
- 是否同时覆盖可辨地标、真实人物尺度和至少一项具体体验；大景是否超越无人空镜，细节是否超越材质广告。
- 在地人物是否拥有真实年龄、职业、服装和技能动作，不同面孔是否自然可见；是否凭空添加不存在的非遗、民族服饰、宗教仪式或节庆。
- 光影、天气、声音和交通是否来自地点本身；是否套用通用金色日落、航拍、古筝、史诗鼓、酒店微笑和连续慢动作。
- 多地点剪辑是否仍保持可理解的水系、路径、建筑材质、地域声音或体验关系；导演风格是否没有把成片改造成犯罪片、悬疑片、仙侠片或爱情预告片。

任一核心目标没有可见证据，或预期观感与用户目标明显不一致，判为“需修改”，先改提示词。

## 三、独立子智能体审稿

- 生成完整草稿后，若 `multi_agent` 子智能体工具可用，必须启动一个独立审稿子智能体；不可用时由当前智能体按同一合同自审。
- 只交给审稿者：用户锁定目标、输出模式、导演机制、完整草稿与本审稿合同。不要泄露自己的怀疑、预设问题或准备采用的修正，避免诱导结论。
- 审稿者只负责审查，不重写整份提示词；输出 `达标/需修改` 与十项检查结果。达标时可不列问题，需修改时列 1–5 个最严重问题及逐项可执行修改，不为凑数虚构缺陷。
- 明确要求审稿子智能体不得继续启动其他子智能体。
- B 模式审稿必须从当前草稿选择一个未在 `cinematic-shot-translation.md` 示范过的镜头执行五问，不能只复述码头反例。
- B 模式、五镜以上片花、人物参考图、多人物关系或用户明确要求高品质时，不得省略独立审稿。

十项检查：

1. 用户核心目标与预期观感是否一致；
2. 导演主机制是否在至少两个画面中产生信息变化；
3. 模型能否按字面执行，而非依赖文学解释；
4. 镜头预算、单镜时长、快慢曲线是否匹配总时长；
5. A 检查每个候选的可见变化与全局摄影语法；B 同时检查空间范围、机位角度、元素分层、起始视觉命题、动作触发、观看关系变化和结束图像，确认不能被普通中景覆盖替代；稳定观察则检查时间、注意力与负空间是否真实改变；
6. 表情是否由事件触发，每镜不超过一个面部变化和一个身体/呼吸信号；
7. 主光是否真实并同时影响人物与环境，皮肤和材质是否避免塑料化；
8. 脸、妆发、服装、道具、轴线和动作是否连续；
9. 配角与环境是否按 `director-world-detail-profiles.md` 参与画面：至少可见年龄/体态/头部轮廓差异、职业化服装分组和地点合理动作；禁止同脸、同发式、同款服装、同步走路与所有导演共用通用群众模板，同时不得抢戏；
10. 是否存在写真、广告、AI 短剧、运镜炫技、提示词过载或摄影器材被模型当作画面元素的风险；最终提示词不得出现升降臂、摇臂、滑轨、稳定器、无人机、灯架、收音杆和工作人员入镜。

十项检查后按所选视频类型追加误判分类：电影预告片使用 `trailer-montage.md`，MTV使用 `music-video.md`，高端文旅使用 `luxury-cultural-tourism.md` 中的类型列表；不符合目标类型时必须说明最主要画面证据并修正。

## 四、修正闭环

1. 优先修正会导致模型错误执行的问题：内容过载、动作时序、镜像、道具、焦点、人物数量和光源冲突；
2. 再修正电影性问题：覆盖式中景、平行跟拍、首尾同构、重复景别、无任务凝视、静态结尾、导演符号空转和环境脱节；
3. 最后压缩形容词、重复参数和负面词，不删除用户锁定事实；
4. 修改后重新生成预期观感并复核十项检查；流程限于首次独立审稿加最多一次同一子智能体简短复核，禁止继续扩展轮次；
5. 只有核心项全部通过，且剩余风险不会改变用户目标时才输出。

## 五、最终展示

默认只展示：

```text
完整最终提示词
预期观感：2–4句，只描述有画面证据的结果
审核结论：达标；如仍有模型固有限制，用一句话说明残余风险
```

用户明确要求审核细节时，再列最重要的 3–6 个问题与已做修改；不要展示冗长子智能体原始记录。
