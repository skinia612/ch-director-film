# 非叙事自由组合片花

本文件用于 A 自由组合（随机）模式：用户不要完整故事和逐镜控制，但需要模型明确知道要生成哪些内容。核心结构是“具体画面素材池＋全局摄影语法”，不是纯氛围描述，也不是逐镜分镜表。

## 1. 固定输出顺序

```text
格式、时长、画幅、时代背景、片花性质与无因果声明。
人物参考、长相连续性、妆发、服装和人物气质。
画面自由组合：6–8个互不连续的具体场景与人物状态候选，最终只选取5–7段。
全局景别、人物占比和单片段时长。
全局焦段光圈、主运镜菜单和运动节奏。
色彩、真实光源、皮肤、服装、建筑和道具材质。
配角规则。
当前任务负面约束。
```

## 2. 画面素材池必须具体

每个候选用一句话回答：

```text
人物/关系 + 具体空间 + 一次可见变化或自然互动 + 一个关键环境细节
```

合格示例：

- 清晨高窗旁，女主从暗处向窗边迈近半步，视线被院中动静吸引；
- 深木书房里，女主翻到夹有旧照片的一页，手停住后抬眼看向门口；
- 老式汽车后排，街景光影掠过车窗和人物面部，她随车辆转弯扶住椅背；
- 暮色庭院中，女主为逆向经过的人让出半步，重新落在朱红宅门与灰砖影壁之间。

不合格示例：

- 高级、唯美、电影感、宿命氛围；
- 女主在不同场景中展现多面气质；
- 若干近中远景交错，光影流动。

- 候选互不连续，不解释前因后果，不写角色任务和戏剧结局。
- 允许站立、行走、翻书、梳妆、坐车、穿过空间、与人群共处等自然状态，但每条至少让方向、距离、视线目标、关系位置、环境接触或受光发生一项变化。
- 候选是素材池，不要求全部出现；未加载视频类型适配器的普通15秒通常列6–8个并明确最终只选5–7段，类型1/2/3由对应适配器覆盖数量，避免再追加隐藏的“若干细节特写”。
- 静态人像候选最多2个，正面居中行走最多1个；至少3个候选含人物关系、环境接触或空间阻力。
- 场景可以多样，但服装、时代、地点和人物身份必须统一；换景不能破坏世界观。

## 3. A与B的边界

A 模式允许：

- 在候选中写一次简短范围，如面部、侧脸、胸像、半身、全身或环境；
- 在个别关键候选中写一个简单运动，如迎面走来、车窗平行移动或人物穿过长廊；
- 在素材池之后统一给出焦段、光圈、景别层级、片段时长和3–6种运镜语法。

A 模式禁止：

- 时间码、镜头编号和逐条拍摄参数；
- 摄影机起点、移动距离、速度曲线、停点、焦点行为和结束画面；
- 每个候选都附带焦段、光圈、机位、运镜和光路；
- 逐候选解释导演机制或创作动机。

一旦需要上述控制，切换 B 精确导演分镜模式，不继续补丁式加参数。

## 4. 全局摄影语法

素材池之后统一写：

- 景别层级：头部、侧脸、胸像、半身、全身、短暂环境画面的使用比例；
- 时长：人物片段占主要时长，单片段通常约0.6–1.8秒；
- 焦段光圈：选择2–4组与任务匹配的焦段和光圈，不让所有画面极浅景深；
- 运镜菜单：选择3–6种主语法，如贴身跟随、短距离前移、侧向平移、轻微弧移、平行移动、稳定观察；只写视点结果，不写实现器材；
- 导演差异：全局语法必须来自所选导演档案，不能所有导演都复用同一菜单。

全局语法只提供模型可选的拍摄倾向，不宣称每个候选必须使用其中全部技术。

## 5. 世界观与服装

- 先写时代、地域、社会环境和建筑，再写漂亮材质。
- 人物参考图必须锁定同一张脸、年龄、发型轮廓和基础妆面；服装可随候选变化，但衣制与时代一致。
- 古代题材正向写明交领、对襟、袖型、长裙、甲胄或发髻结构，避免现代礼服轮廓。
- 画面出现配角或群众时读取 `director-world-detail-profiles.md`：按身份、年龄、体态、脸部/头部轮廓、发式、服装层级、持有物和职业动作建立差异，禁止同脸、同发髻、同胡须和同款服装复制。
- 用户要求配角不露脸时，可以出现不同年龄与体态的背影、侧后轮廓、肩部、手部、衣袖和裙摆；仍须通过头部轮廓、发式、服装和步态区分，不把所有人做成相同黑影。
- 用户未要求隐藏配角面孔时，允许背景人物短暂出现自然侧脸或四分之三脸，但不看镜头、不占据中心、不获得主角同等级焦点与受光。
- 群众服装按职业、阶层和活动状态形成3–6个受控色族与不同轮廓，不再默认“全员灰青”；具体密度、个体化程度和动作节奏服从所选导演。
- 背景人物必须完成地点合理的生活动作，不得全部慢走、站立或看主角；每个短片段只保留2–4类背景动作，避免过载。

## 6. 光影与真实质感

- 列出场景中真实存在的窗光、天空光、灯笼、壁灯、烛光、车窗反射、水面或雪地反射。
- 人脸可以有柔暗侧，不要求每个候选维持相同完美曝光。
- 皮肤保留自然微纹理、轻微色差和克制高光；避免磨皮蜡感、白色油光和HDR边缘。
- 丝绸、丝绒、羊绒、木器、玻璃、石材、金属和水面必须保持不同反射特征。
- 色彩系统控制在一个主色组和少量辅助色，不用统一金黄滤镜或橙皮青影。

## 7. 反广告预检

- 候选不能全部是正面行走、窗边静站、镜前梳妆和面部凝视；至少加入空间、交通、环境或人群状态变化。
- 美妆、珠宝、湿发、水珠、眼睛和手腕等广告化元素不连续堆叠。
- 全局运镜菜单不超过6种，不追加360度环绕、无尽漂浮和反复变焦。
- 正向正文先避免现代错装、发光皮肤和香水广告组合，不能只靠末尾负面词修补。
- “单独美女＋水面/灯笼/月洞门/石桥＋飘动丝裙＋慢走/转圈＋正面美容近景＋青蓝橙灯”出现四类以上时，必须替换动作、空间关系或光源结构。
- 非舞蹈、非武打内容不使用原地旋转、连续转身、甩袖甩裙表达灵动；衣料只作为身体动作的次级反应。

## 8. 输出前检查

1. 候选数量与最终选取数量是否符合所选视频类型适配器；未加载类型适配器时是否使用6–8选5–7段？
2. 候选是否避免意外组成跨镜因果链，并符合所选类型的音乐段落、预告片碎片或文旅体验结构？
3. 是否只在后文统一写摄影语法，没有逐候选半具体控制？
4. 人物长相、时代、服装和配角规则是否连续；群众是否存在同脸、同发式、同装与同步动作？
5. 所选导演是否真正改变候选内容、全局运镜、色彩光影、群众密度和背景生活方式，而不是只出现名字？
6. 真实皮肤、光源和材质是否通过正向描述成立？

任意一项不满足先重写；若用户开始要求逐镜路径和控制信息，切换 B 模式。
