# CHDirectorFilm

CHDirectorFilm 是一个面向 Seedance 2.0 的 Codex Skill，用于把人物、场景、音乐、目的地和片花需求编译为具有明确导演摄影语法的中文视频提示词。

它重点控制镜头怎样拍，而不只描述故事发生了什么：画面范围、焦段光圈、起始构图、人物表演、摄影机路径、环境光、材质、剪辑节奏和结束状态都会根据任务需要组织起来。

## 主要能力

- 支持 **A 自由组合（随机）模式**：提供具体画面素材池，再统一规定景别、焦段、运镜、光影和质感。
- 支持 **B 精确导演分镜模式**：按时间码逐镜描述起始画面、人物动作、运镜路径、光影变化和结束状态。
- 通过 **导演编号—视频类型—生成模式** 三层选择，一次确定主导演、电影预告片/MTV/高端文旅和 A/B 控制精度。
- 支持独立的 **电影预告片快剪层**：覆盖独立事件选材、弹性镜长、锚点与闪切、配乐同步点和生产声音桥。
- 支持独立的 **MTV / 音乐影像层**：覆盖歌曲段落、表演身份、视觉副歌、口型/演奏边界和音乐响应剪辑。
- 支持独立的 **高端文旅宣传片层**：覆盖目的地识别、真实文化生活、人物体验、地域声音和品牌余韵。
- 支持张艺谋、徐克、王家卫、刘伟强与麦兆辉、李安、冯小刚、贾樟柯、陈可辛、关锦鹏、杜琪峯十种摄影语法。
- 按需加载动作场面和文戏表演适配器，处理动作因果、重量反馈、情绪触发、反应延迟和道具连续性。
- 控制真实皮肤、方向明确的环境光、不同材质反射和人物跨光区变化，降低塑料皮肤、假光和 AI 短剧感。
- B 模式强制执行镜头视觉转译：检查摄影机观察位置、动作触发、观看关系变化和结束图像，拦截“中景＋横移＋人物完成动作”的短剧覆盖镜头。
- 最终提示词只描述画面视点的高度、方向、路径和停止状态，不输出升降臂、摇臂、滑轨、稳定器、无人机等器材名称，防止视频模型把片场设备生成进画面。
- 配角和群众不是通用灰青背景：Skill 会按所选导演分别控制年龄体态、面孔发式、职业与阶层服装、生活动作、群众密度以及人物如何进入构图；即使要求不露脸，也必须通过轮廓、发式、服装和步态避免克隆。
- 识别民国写真、香水广告、正面走秀、原地转圈、长时间凝视、无意义遮挡和炫技运镜等廉价化风险。
- 输出前执行“目标—预期观感—独立审稿—修正”闭环；子智能体不可用时按同一合同自审。

## 工作流程

```mermaid
flowchart LR
    A[用户需求] --> B[选择导演编号]
    B --> C[选择视频类型]
    C --> D[选择 A 或 B 模式]
    D --> J{类型适配层}
    J -- 电影预告片 --> K[独立事件与弹性快剪]
    J -- MTV --> M[歌曲段落与视觉副歌]
    J -- 高端文旅 --> N[地域体验与品牌余韵]
    K --> L[编译完整提示词]
    M --> L
    N --> L
    L --> E[反推预期观感]
    E --> F[独立子智能体审稿]
    F --> G{是否达标}
    G -- 否 --> H[修正提示词]
    H --> E
    G -- 是 --> I[输出最终提示词与审核结论]
```

独立审稿只允许首次审稿加最多一次复核，避免无限迭代。默认不展示冗长审稿记录，只输出最终提示词、简短预期观感和审核结论。

## 快速使用

在 Codex 中明确调用：

```text
使用 $ch-director-film，为我生成一段15秒、16:9横屏的民国女性电影片花。
选择9-1-B：关锦鹏摄影语法、电影预告片、B精确导演分镜。
```

如果请求没有明示导演、视频类型或 A/B 模式，Skill 会一次列出缺失层；已经明示的层级不会重复询问。

## 三层选择

可以直接用 `导演编号-视频类型-生成模式` 回答，例如 `3-2-B`：

| 层级 | 选择 |
|---|---|
| 导演编号 | 1张艺谋、2徐克、3王家卫、4刘伟强＋麦兆辉、5李安、6冯小刚、7贾樟柯、8陈可辛、9关锦鹏、10杜琪峯 |
| 视频类型 | 1电影预告片、2 MTV / 音乐影像、3高端文旅宣传片 |
| 生成模式 | A自由组合（随机）、B精确导演分镜 |

示例：

```text
3-2-A：王家卫语法的MTV，自由组合候选画面。
5-3-B：李安语法的高端文旅片，按时间码精确分镜。
1-1-B：张艺谋语法的电影预告片，按时间码精确分镜。
```

“随机”只表示由模型从受控候选池中自由选择和组合，不表示随机导演风格、人物外观或画面质量。

## A 与 B 如何选择

| 模式 | 适合需求 | 输出特点 |
|---|---|---|
| A 自由组合片花 | 不解释剧情、不要完整因果、让模型自由组合画面 | 6–8 个画面候选，最终选取 5–7 段；摄影参数统一放在素材池之后 |
| B 精确导演分镜 | 要求时间码、焦段、光圈、构图、人物动作和运镜路径 | 通常 4–5 镜；逐镜给出起始状态、单一运镜、光影变化和结束状态 |

不要混用两种模式。A 模式不逐条绑定复杂摄影路径；一旦要求具体起点、距离、速度、焦点和停点，应整体切换到 B 模式。

## 三类视频适配层

### 1. 电影预告片

当请求中明确出现“电影预告片、预告片快剪、trailer、teaser、片花式预告”时，Skill 会在 A/B 模式之上加载预告片适配层：

- 先锁定题材气质、导演可见机制、人物银幕气质、能量曲线和余韵，不强制建立卖点命题、中心悬念或剧情逻辑。
- 预告片由不同时间与地点的独立事件碎片构成；每组通常一个镜头，最多一组使用两个相关镜头，其余不承担跨镜因果。
- 每个镜头须提供导演构图或光影、人物表现、关系气息、题材行为、环境戏剧、制作规模或触觉质感中的明确画面价值；美感可以成立，但不能退化为写真、走秀或景区显露。
- 不按到达、行动、结果的时间顺序压缩事件，而从签名画面、人物近景、独立关系碎片、题材动作、地标规模、环境作用和余韵按钮中选镜。
- 15 秒通常呈现 8–10 个镜头，采用 2–3 个锚点镜头与 5–7 个闪切镜头；镜长有明显长短差，快剪段中保留一次极短呼吸。
- 配乐采用开场稀疏动机、中段脉冲、短促加速和结尾按钮的三段能量；只设置 2–4 个主要画面同步点，不机械一拍一切。
- 至少保留一个水声、脚步、衣料、门轴、兵器、钟声或人群声组成的生产声音桥，并可用一次 J-cut 或 L-cut 串联非连续画面。
- 实景参考图锁定地标、建筑、水岸与空间关系，不把真实景区改成虚构仙宫，也不做无人旅游宣传空镜。

A 模式会提供 10–12 个互不连续候选并让模型选取 8–10 个；B 模式用完整合同控制锚点镜头，用轻量硬合同控制闪切镜头。闪切可以简化灯光工程和动作过程，但仍必须写清空间范围、机位角度、前中后景元素、主体位置、运镜终点和切出状态。

### 2. MTV / 音乐影像

- 先锁定歌曲来源、片段位置、速度感、主要重音、人声状态、表演身份和视觉副歌。
- 支持表演型、概念型、叙事型或两种形态混合；15秒只保留一个主形态和一个辅助形态。
- 主歌负责建立空间与艺人状态，副歌让一个动作、构图、场景或色彩母题重复并升级，桥段或停顿制造对比。
- 可见演唱必须绑定用户提供且有权使用的歌词片段；没有歌曲或未要求口型时，默认原创无歌词结构并避免人物无意义张嘴。
- 剪辑可响应鼓点、旋律、人声换气、歌词意象、动作峰值或音色变化，只设置少量关键同步点，不一拍一切。
- 至少保留一个较完整的艺人或主角表演锚点；舞蹈显示完整身体和落脚，演奏显示正确乐器、手位与受力。

A 模式提供8–12个候选，统一给出歌曲段落和视觉副歌；B 模式逐镜增加“音乐段落、响应音点、演唱状态”控制。审稿会区分真正的 MTV、电影预告片、时尚广告、机械卡点混剪和舞台记录。

### 3. 高端文旅宣传片

- 先锁定目的地身份、品牌气质、核心体验、在地人物、地域声音与记忆母题。
- 15秒通常使用“签名地点—空间进入—文化/生活接触—制作峰值—品牌余韵”，不强编冲突和悬念。
- 景观、建筑、当地生活、文化技艺、饮食和人物体验至少覆盖三类；只切换美景不算高端文旅。
- 在地人物拥有真实年龄、职业、服装和技能动作，不清空社会环境，也不把居民拍成统一群众演员。
- 高端质感来自真实时间、光线、材质、服务与稀缺体验，不依赖通用日落、航拍、慢动作、酒店微笑和金色滤镜。
- 实景参考图只绑定可确认的地标、路径、开敞面和采光，不补造非遗、民族服饰、宗教仪式或大型建筑。

A 模式提供8–12个地点与体验候选，统一给出地域母题和声音曲线；B 模式逐镜增加“地域识别或体验价值”控制。审稿会区分高端文旅、旅行Vlog、景区集锦、房地产/酒店广告、电影预告片和音乐录像。

## 推荐输入结构

信息不必写成长故事，提供下列内容即可：

```text
时长与画幅：15秒，16:9横屏，24fps
内容：人物、关系、空间和主要事件
导演摄影语法：从支持列表选择一种
视频类型：电影预告片 / MTV音乐影像 / 高端文旅宣传片
输出模式：A自由组合 / B精确分镜
人物要求：年龄、气质、妆发、服装、参考图规则
情绪与质感：亲密、压迫、宿命、轻快、纪实等
必须出现：场景、动作、道具或关系信息
必须避免：天气、运镜、服装、表演或画面风险
```

## 人物参考图

使用 `@图片1` 时，建议明确参考范围，避免模型把参考图中的造型和背景一并复制：

```text
女主面部身份以@图片1作为唯一参考：只继承脸型、五官比例和可识别面部特征；
不继承参考图中的发型、妆容、身材、服饰、姿势、背景、光线和画面风格。
所有镜头保持同一张脸，不与配角混脸。
```

请确保对上传人物图像拥有合法使用权限；公开发布案例前应确认人物肖像和素材授权范围。

## 支持的摄影语法

| 导演语法 | 主要视觉特征 |
|---|---|
| 张艺谋 | 绘画式整体造型、色块、仪式空间与环境色参与叙事 |
| 徐克 | 动态空间重组、表现性环境光、危险感与动作方向变化 |
| 王家卫 | 低照度实景光、时间错位、遮挡与亲密疏离 |
| 刘伟强＋麦兆辉 | 金属冷调、身份悬疑、光学反射与精准商业摄影 |
| 李安 | 克制人文、自然主义光线、礼节动作与关系距离 |
| 冯小刚 | 群像可读性、类型化商业现实主义与事件链调度 |
| 贾樟柯 | 真实环境、社会时间、稳定观察和环境内部运动 |
| 陈可辛 | 演员关系、共同动作、情感推进和通俗剧现实质感 |
| 关锦鹏 | 女性主体、镜像与门框、记忆性光影和细腻室内调度 |
| 杜琪峯 | 几何站位、夜间高反差、固定蓄势与短促爆发 |

导演姓名只用于选择生产语法。最终提示词会把风格转译成可见的构图、运镜、光源、表演和剪辑，不依赖简单地写“某导演风格”。

## 输出审稿

每次生成完整草稿后，Skill 会从提示词反推 2–4 句预期观感，并检查：

1. 用户核心目标与生成后的实际观感是否一致；
2. 导演机制是否真正改变构图、运动、光影或表演；
3. 镜头预算和单镜时长是否匹配总时长；
4. 表情是否由事件触发，人物是否会僵硬或过度表演；
5. 光源是否同时影响人物与环境，皮肤和材质是否真实；
6. 人物、服装、道具、轴线和动作是否连续；
7. 是否存在写真、广告、AI 短剧或提示词过载风险。

并按视频类型追加专项判断：预告片是否连续叙事，MTV是否具有音乐合同和视觉副歌，文旅片是否具有不可替换的地域身份和真实体验。

发现问题后先修改，再输出最终版本。达标时不会为了展示审稿过程强行虚构问题。

## 镜头视觉转译

B 模式不会因为写了焦段、光圈、轨道距离和结束状态就自动判定为电影镜头。每镜必须形成以下链条：

```text
起始视觉命题 → 动作触发 → 观看关系变化 → 结束图像
```

如果摄影机只在岸边、走廊或桌旁平行记录人物完成动作，删掉运镜后信息完全不变，或结尾只追加自然对视、手部和道具露出，该镜头会被判为短剧覆盖并重写。固定镜头可以成立，但画面内部必须发生纵深交换、遮挡显露、重心传递、光区跨越或焦点接管。

## 使用原则

- 用户锁定的事实高于审美偏好，镜头可执行性高于文学修辞。
- 画面美感来自人物、空间、光源和摄影机的共同组织，不靠堆叠“高级、电影感、史诗感”。
- 表演灵动来自视线目标、反应时间、重心变化和动作回弹，不等于原地转圈、甩袖或连续回眸。
- 近景用于捕捉决定性变化，不用于长时间面部凝视。
- 前景遮挡必须由人物路线或空间结构触发，并在显露后提供新信息。
- 负面词不能修复正文中的错误设计；发现广告化或假光组合时，应先重写正向画面。

## 限制

- 视频模型仍可能在镜像、多人手部、复杂道具交接和人物连续性上产生误差。
- 参考图一致性取决于目标平台对人物参考的支持程度。
- 精确分镜不是传统制片分镜表的替代品；它用于提高生成视频的可控性和画面一致性。
